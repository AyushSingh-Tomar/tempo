## 7.2 Data-type normalization

Processing the same file with the same configuration should produce the same standardized data and mapping outcomes, apart from explicitly variable metadata such as timestamps.

Do not allow nondeterministic LLM responses to silently change accepted mappings between identical runs without a documented, reviewable mechanism.
